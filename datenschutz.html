Datenschutzerklärung

Familien-Dashboard · Stand: November 2026

Wer die Anwendung nutzt

Das Familien-Dashboard ist eine private Anwendung, die ausschließlich von den Mitgliedern eines einzelnen Haushalts genutzt wird. Sie wird nicht öffentlich angeboten.

Welche Daten verarbeitet werden

Mit Zustimmung des angemeldeten Google-Kontos greift die Anwendung auf folgende Daten zu:

  • Google Kalender: Termine der freigegebenen Kalender werden gelesen und angezeigt. Über das Dashboard angelegte Termine werden in Google Kalender gespeichert; Termine können darüber auch gelöscht werden.
  • Google Tasks: Die Einkaufsliste wird gelesen und bearbeitet (Einträge hinzufügen, abhaken, löschen).

Zusätzlich wird lokal gespeichert, welche Artikel häufig auf der Einkaufsliste stehen, um sie als Schnellauswahl anzubieten.

Wo die Daten liegen

Die Anwendung läuft auf einem Rechner im privaten Heimnetz. Die Anmeldedaten (Zugriffstoken) und die Schnellauswahl werden nur dort gespeichert. Kalender- und Aufgabendaten werden nicht dauerhaft kopiert, sondern bei jeder Anzeige direkt bei Google abgerufen.

Weitergabe an Dritte

Daten werden nicht an Dritte weitergegeben, nicht verkauft und nicht für Werbung verwendet. Für die Wettervorhersage werden lediglich die Koordinaten des Wohnorts an den Wetterdienst Open-Meteo übermittelt – ohne Bezug zu Kalender, Einkaufsliste oder Google-Konto.

Google API Services User Data Policy

Die Nutzung und Übertragung von Informationen, die über Google-APIs empfangen werden, erfolgt gemäß der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Zugriff widerrufen

Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden. Danach kann die Anwendung keine Daten mehr abrufen.
